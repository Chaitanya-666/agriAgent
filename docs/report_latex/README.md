# AgriAgent black-book report (LaTeX)

Department rule (Nov 2026): the report must be a LaTeX file, references in IEEE format with
at least 25-30 Transactions / reputed-journal papers. This folder replaces
`docs/thesis/AgriAgent_Final_Report.typ` for submission.

    cd docs/report_latex && tectonic main.tex       # or Overleaf (pdfLaTeX/XeLaTeX + BibTeX)

- `layout.tex`: all page styling, matched to a VJTI department Stage II report (kept locally
  in `EXTERNALTEMPLATE/`, git-ignored). Change only this file if the department format differs.
- `main.tex`: title, names, roll numbers (fill `\rollB`..`\rollD`, `\hod`), chapter order as
  in the department guideline (Motivation, Literature Survey, Gaps, Objectives, Proposed System,
  Results + Mathematical Model, Conclusion, Future Scope, References).
- `references_crossref.bib`: GENERATED by `refs/build_bib.py` from Crossref for the DOIs in
  `refs/dois.tsv`. Never edit by hand. `references_manual.bib`: preprints, datasets, docs.
- `refs/abstracts/`: the abstracts each survey summary was written from
  (`refs/fetch_abstracts.py`; Semantic Scholar, OpenAlex, arXiv).
