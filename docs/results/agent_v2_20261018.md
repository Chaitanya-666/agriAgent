# Escalation agent on the 38-image set (RQ2), 18 Oct 2026

Setting: deployed gate (confidence 0.70) plus the escalation agent reviewing up to 3 withheld
plants per photo (row rule -> Clef Flash -> Groq qwen3.8-27b, naive-Bayes combination, decide
at P(weed) >= 0.85). Same detections as the baseline. Groq free tier: 14 of 69 Groq calls failed
on the per-minute rate limit and counted as "no answer". Run time about 40 minutes.

Spray map: identical with and without the agent (sugar beet: 0.0% crop pixels sprayed, 0.0% weed
recall; cotton: 0.0% weed recall), because the agent never answered "weed".

Agent verdicts on the 69 reviewed plants, scored against the official labels (a plant counts as
crop or weed by which labelled vegetation its SAM 2 mask covers more):

| plant really was | agent: weed | agent: crop | agent: unsure |
|---|---|---|---|
| crop (44) | 0 | 13 | 31 |
| weed (25) | 0 | 1 | 24 |

Reading: never approved spraying a crop plant; "crop" verdicts 13/14 correct; but 24 of 25 real
weeds stayed withheld, so no weed recall was added. For comparison, the rule-based plant
classifier (docs/results/holdout_plant_rules_v3_20261018.md) reaches 77.9% weed recall on 90
held-out photos at no model cost. Conclusion: escalation to the slow models is safe and precise
but not effective for the crop-versus-weed decision on this data.
